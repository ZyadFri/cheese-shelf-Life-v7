# Standing instructions for this project

- After any meaningful update to this project, commit and push to
  https://github.com/ZyadFri/cheese-shelf-Life-v7 (remote `zyad`, branch `main`)
  without asking for confirmation first — the user pre-authorized this.
  Follow the existing `.gitignore` (no `.venv`/`node_modules`/build output,
  no trained model artifacts, no secrets). Never include a
  `Co-Authored-By: Claude` line in commit messages for this project.
